# Changelog

All notable changes to `volto-existing-block` will be documented in this file.

## [0.2.0] - 2026-10-24

### Bug Fixes & Compatibility
- **Volto 19 Compatibility:** Updated `peerDependencies` to support `@plone/volto` 17, 18, and 19 (`>=17.0.0 || >=18.0.0-alpha.0 || >=19.0.0-alpha.0`).
- **SSR Optimization:** Integrated `@loadable/component` to optimize client-side loading performance without interrupting SSR.
- **Styling:** Updated default embed block layout and container styles.

## [0.1.0]

### Initial Release
- Initial release of `volto-existing-block` allowing editors to embed external/internal page elements by URL and DOM ID.
